# SEM Ingeniería

Sitio web corporativo de SEM Ingeniería — réplica en Astro del sitio [semingenieria.com.py](https://semingenieria.com.py/).

## Desarrollo

```bash
npm install
npm run dev
```

## Build y despliegue (Cloudflare Workers)

```bash
npm run build
npx wrangler deploy
```

O en un solo paso: `npm run deploy`.
